This site publishes verified snapshots of public F5 product documentation for
machine consumption.

- Start with [`llms.txt`](../llms.txt) for source-level navigation.
- Use [`llms-full.txt`](../llms-full.txt) for the complete link inventory.
- Follow `/_llms-txt/<source>/<path>.txt` links for progressively narrower
  indices and full-document leaves.
- Inspect [snapshot provenance](../snapshot/snapshot-provenance.json) and the
  [verified manifest](../snapshot/manifest.json) for the immutable publication
  identity.

The scraped corpus is deliberately outside this site's HTML content
collection. Only this landing page is rendered as human-facing documentation.
