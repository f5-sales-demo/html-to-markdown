## A collection you can navigate

This project converts public source pages to Markdown and publishes a curated collection.
Curation policies keep the collection focused and useful. More policies can be added as the
collection grows.

## Use the curated Markdown

- [Source and topic index](/html-to-markdown/llms.txt): start browsing the collection.
- [Complete document inventory](/html-to-markdown/llms-full.txt): find every published document.
- [Verified snapshot manifest](/html-to-markdown/snapshot/manifest.json): inspect document and asset counts.
- [Snapshot details](/html-to-markdown/snapshot/snapshot-provenance.json): identify the exact published snapshot.
