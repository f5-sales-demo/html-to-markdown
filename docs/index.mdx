This site publishes verified snapshots of public F5 product documentation for
machine consumption.

- Start with [`llms.txt`](/html-to-markdown/llms.txt) for source-level navigation.
- Use [`llms-full.txt`](/html-to-markdown/llms-full.txt) for the complete link inventory.
- Follow `/html-to-markdown/_llms-txt/<source>/<path>.txt` links for progressively narrower
  indices and full-document leaves.
- Inspect [snapshot provenance](/html-to-markdown/snapshot/snapshot-provenance.json) and the
  [verified manifest](/html-to-markdown/snapshot/manifest.json) for the immutable publication
  identity.

The scraped corpus is deliberately outside this site's HTML content
collection. Only this landing page is rendered as human-facing documentation.
