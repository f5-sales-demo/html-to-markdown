# Authored legacy classifications

The `legacy-retired` topic runs before SMSv2, AppStack, CLI retirement,
Terraform and API migration. Explicit legacy page titles, authored tags,
metadata and deployment scope remove the whole page. A current product name
inside a legacy migration procedure does not qualify that procedure for
retention. Exact retired URLs remain excluded when upstream content changes.

Mixed pages and incoming dependencies require a committed review of the
original authored metadata and body, complete structural sections and source
and output digests. Changed inputs and new affected URLs are omitted. Reviews
retain current DNS, load-balancer and role instructions only when they stand
independently; no retirement notice or compatibility guidance is added.

The pinned baseline is `content-20261007T014508Z`, publication SHA-256
`7f1dfd04b40b91120057a7d2444a4a3d1489ac2f809c95d5129111046b00773b`.
`legacy_review.json` records exact retired identities and reviewed decisions.
Fresh authored HTML fixtures cover the migration, migration utility, cloud,
KVM and VMware image examples. Their source and authored-content digests are
recorded separately from the consumer corpus.

Matching decodes case, nested percent encoding, HTML entities and character
escapes across descriptions, headings, code, captions and destinations. Normal
extraction inspects authored HTML and head classifications before link
rewriting; an unreviewed affected HTML input is omitted. Offline curation checks
original metadata before enrichment. Derived relationships are rebuilt rather
than treated as authored instructions.

Workload and cloud migration, legacy applications, third-party requirements
such as legacy BIOS, ordinary Kubernetes APIs, and illustrative customer API
versions remain valid. Generic DNS delegation and non-delegated ACME challenges
are distinct from the retired Delegated Domains feature. Current API namespaces
remain supported; exact retired namespaces and their migration guide do not.

Manifest schema v2 and CLI options remain unchanged. Detailed retirement and
OCR evidence belongs to the separate curation audit and engineering review;
consumer reports, archives, navigation and search contain retained content.
