# Scoped public media capture

MyF5 references a static Slack gear emoji and an Enzoic credential-stuffing versus
brute-force diagram. Independent HTTPS probes returned PNG bytes from the original
authorities without redirects. The scraper permits the exact Slack standard-emoji
version and Enzoic upload-image namespaces, without adding either host to the global
asset allowlist. Queries, fragments, ports, user information, encodings and unrelated
paths fail; every redirect destination still passes the same asset policy.

Capture eligibility grants no publication approval. Complete article and native-media
privacy, relevance, retirement and independent preservation checks remain mandatory.
The probe responses, images and unresolved Salesforce, GitLab and Silverline evidence
remain private. Other inaccessible media stay in the exception queue.
