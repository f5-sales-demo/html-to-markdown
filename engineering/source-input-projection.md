# Complete source inputs within native request limits

Codex turn/start accepts at most 1,048,576 text characters. Repeated SVG metadata and
text-edit guards for noneditable media fields caused complete source reviews to exceed
that limit before inference.

The controller supplies full source fields once and replaces repeated frame metadata
with exact field references. It supplies text-edit guards only for fields the original
output schema permits editing. Original articles, markup, findings, metadata and every
native media attachment remain preserved. Reconstruction verifies the complete original
data; actual request and response hashes remain bound to the actual native invocation.
The private logical request and projection proof remain separate from consumer content.

Projection composes with independently validated native-media partitions. Offline replay
rejects missing or changed projection, source, reference, guard or response evidence.
Existing approved records replay their immutable logical requests; a controller upgrade
grants no privacy corrections. Unprojectable oversized inputs retain their complete
private request and fail before invoking a model.

Qualification used the actual oversized source requests, including a privacy input
reduced from 2,935,139 to 621,499 characters. Complete source reconstruction and
unchanged image attachments passed. Historical MyF5 and Community admissions replayed
without inference or changed receipts. Detailed captures, model payloads and responses
remain private.
