# Portable native review images

Native source and retirement-candidate frames use the shared lossless PNG encoder in
`media_encoding.png_bytes`. Explicit stored compression keeps the complete RGB pixels and
produces identical bytes on Mac and Ubuntu despite their different default zlib backends.
OCR receives those same encoded bytes. Each observation retains the source digest, visual
digest, complete frame count, dimensions, timing, loop and captured metadata.

The original captured asset stays unchanged. Animated media supplies every full-resolution
frame; frame preparation never replaces the published animation with a single image.

Historical model requests remain bound to their original software, policy, schema and encoded
images. Replay their preserved bodies with the qualified historical controller and native encoder
profile. A new encoded image has its own request hash. Preserve each original response and
correction ledger, and verify source, transformations, pixels, placement and exact byte custody
before composing historical evidence. Pixel equality alone cannot rebind a response to a different
request or grant source, retirement, planner or publication approval.

Raw captures, OCR, native derivatives, model responses and transformation evidence stay in
private qualification storage. Consumer archives contain published content, retained assets and
safe provenance.
